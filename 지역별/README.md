# 원하는 지역의 경매 자료 보기

제품 폴더에서 최초 한 번 `python setup-lab.py`로 설치하고 `python 지역별/지역선택.py`를 실행하세요. Python 3.11 이상과 인터넷이 필요합니다. API 키·유료 AI 계정은 필요하지 않습니다. Windows에서는 같은 명령을 터미널에 입력할 수 있으나 Windows 실실행은 미검증입니다.

1. 시·도 목록에서 번호를 선택합니다.
2. 공식 사이트에서 불러온 시·군·구 목록을 선택합니다. `0`은 시도 전체입니다.
3. 매각 시작일과 종료일을 `YYYY-MM-DD`로 입력합니다.
4. 표시된 결과 폴더에서 원하는 지역의 `records.xlsx` 또는 `overview.csv`를 엽니다.

```text
수집결과/작업폴더/
  records.xlsx          전체 저장 자료
  overview.csv          주소·용도·가격 표
  manifest.json         조건·수집 상태·파일 해시
  지역별/
    지역목록.csv         지역별 저장 건수와 폴더
    서울/
      11680_강남구/
        records.xlsx
        overview.csv
        records.csv
        records.jsonl
        manifest.json
```

기본 한도는 초기 연결·시군구 코드 조회·재시도를 포함해 10회이며 한 번에 1페이지를 수집합니다. `python 지역별/지역선택.py --max-pages 2`로 두 페이지까지 진행할 수 있습니다. 부분수집이면 표시된 작업 ID로 `court-auction-mcp collect --job-id ID`를 실행해 재개합니다. 같은 작업의 누적 한도는 초기화되지 않습니다. 이어서 export를 실행하면 새 결과 폴더가 생깁니다.

공식 목록은 사이트가 제공한 명칭 기준입니다. 확인된 테스트구(11745)는 선택에서 제외하며, 행정구역의 현행·폐지 여부 전체를 별도로 보증하지 않습니다.

주소 없는 자료는 지역미확인으로 보존합니다. 지역별 건수는 이번에 저장한 목적물 행 수이며, 전국 전체 경매 수나 개별 매물 수가 아닙니다. Excel의 조건검증이 unverified이면 복원 시트의 누락 이유를 확인하세요. 가격이 같은 물건의 여러 목적물에 반복될 수 있어 행별 합산에 주의하세요. 실제 입찰 전 법원 원문을 재확인해야 합니다.

받는 사람에게 프로그램만 전달하면 직접 지역을 골라 수집할 수 있습니다. 이미 수집한 자료를 전달하려면 해당 작업폴더 전체를 공유하면 됩니다. 배포 ZIP에는 실제 물건 자료가 포함되지 않습니다.
