# 예제

`run_example.py`는 `synthetic.json`만 사용한다. 사건번호 2099타경123과 주소는 모두 가상이며 외부 요청이 없다. 토지·건물 2행을 같은 사건에 넣어 식별·저장·복원을 확인한다. 출력은 새 임시 폴더이며 경로가 마지막 JSON에 나온다.

`query.json`은 실제 검색용 조건 템플릿이다. 법원 또는 시도와 날짜 범위를 직접 바꾼 다음 CLI search/collect에 전달한다. `mcp-config.json`은 클라이언트에 수동으로 추가할 예시이며 운영 설정을 수정하지 않는다. 가상환경을 활성화하지 않았다면 command를 설치한 실행 파일의 절대 경로로 바꾼다.
