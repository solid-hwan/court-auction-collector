# 검증 기록

2026-10-26 · v0.1.0 · SIONLAB

## 제한 실조회

새 패키지에서 서울중앙지방법원(B000210), 매각기일 2026-10-26~2026-11-30을 지정했다. HTTP는 순차로 최소 3초 간격, 총 **9회(초기 연결 4회 포함)**였다. 토큰·쿠키·관계인·실제 수집 자료를 공개 저장소와 ZIP에 넣지 않았다.

| 항목 | 관측 결과 | 한계 |
|---|---|---|
| 한 페이지 검색 | 10행, 원본 전체 건수 475 | 전체 475행 수집을 뜻하지 않음 |
| 15A 상세 | 검색에서 얻은 사건 1개, 법원·사건 식별 일치, 물건/목적물/기일 각 1개 | 다른 사건·복수 물건 상세는 가상 회귀로 보완 |
| 두 페이지 수집 | 20행 읽음·고유 20행 저장, 다음 페이지 3, 호출 3회 | 의도한 page_limit의 부분 수집 |
| 조건 검색 | 10행, 원본 전체 건수 160; 기간·감정가 1억~10억·최저가 5천만~8억·유찰 1~5회 모두 일치 | 건물 매각물건에 연결된 토지 목적물 2행 포함 |

건물 필터를 사용해도 단독주택의 토지 목적물이 함께 나왔다. 같은 법원·사건·매물로 묶어 건물 목적물이 함께 있는 것을 대조했다. 토지를 삭제하지 않고 검색 용도와 목적물 분류를 분리했다. 전국 법원, 지역/세부 용도 조건의 실조회, 전체 수집 완료, Windows 실행은 미검증이다.

## 오프라인 시험

`python -m unittest discover -s tests -v`와 `python examples/run_example.py`를 사용한다. 테스트는 httpx MockTransport와 가상 데이터뿐이며 외부 네트워크를 호출하지 않는다.

시험은 다물건·법원 간 사건번호 충돌·토지/건물·엄격 값 해석·누락 이유·상세 식별자·개인정보 제외·중단/재개·누적 예산·5xx 1회 재시도·차단 영속화·페이지 중복·전체 건수 변화·원자 롤백·장문 Excel/CSV 복원·CLI/Python/MCP 일치·실제 stdio 서브프로세스·ZIP 파일별 해시를 다룬다.

첫 시험에서 Excel 원문은 복원됐으나 Python CSV 읽기의 기본 128KiB 제한을 발견했다. `restore_csv()`를 추가하고 제어문자·유니코드가 있는 128KiB 초과 행의 JSONL/CSV/XLSX 일치를 확인했다.

최종 반복 시험·새 ZIP 설치·GitHub CI의 실제 결과는 아래 표에 기록했다. 공개 ZIP 무결성 대조 결과와 최종 파일 SHA-256은 릴리스 설명과 첨부 해시 파일에서 확인한다. 이 문서의 실조회는 당시 제한된 범위의 관측이며 정상 동작을 지속 보장하지 않는다.
